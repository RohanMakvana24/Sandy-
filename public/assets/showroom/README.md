`boutique-preview.webp` is a screenshot rendered from this project's actual React Three Fiber room, compressed to 1280 × 720 WebP. It is used only on the section entry card. Enter the showroom lazy-loads the live navigable 3D geometry; the screenshot is not used as a room background or panorama.

Product thumbnails are inline SVG concept illustrations generated by `productThumbnail` in `src/utils/showroomCatalog.ts`. All are explicitly generic concepts, awaiting approved salon assets.
